# Anushka Chaturvedi — Profile Card Project

A responsive, single-file profile page created as part of the **Web Development Day 6 Assignment** based on CSS Box Model, Display, and Positioning concepts.

## Assignment Features

- Profile hero section with decorative shapes using `position` and `z-index`.
- Three attractive rounded card styles: Light, Dark, and Accent.
- Sticky navigation bar.
- Fixed floating Back-to-Top button.
- Notes panel with scrollable content using `overflow: auto`.
- Responsive horizontal tile strip.
- CSS Box Model illustration showing Content, Padding, Border, and Margin.
- Responsive layouts for desktop, tablet, and mobile devices.
- Global `box-sizing: border-box` property.

## Technologies Used

- HTML5
- CSS3
- CSS Box Model
- Flexbox
- Positioning
- Responsive Web Design

## Project Structure

- `index.html` — Main profile card webpage containing HTML and CSS.

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using Live Server or open it directly in a browser.
